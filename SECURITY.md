# Security Policy

## Scope

HPSS is research software for compact textual representations and collision analysis. It is not intended to provide cryptographic security, password protection, authentication, or adversarially robust hashing.

## Reporting a security issue

If you believe you have found a security issue in the software, please avoid posting sensitive details in a public issue. Use GitHub's private vulnerability-reporting mechanism if it is enabled for this repository.

If private reporting is unavailable, open a public issue containing only enough information to identify the affected component and request a private discussion with the maintainer. Do not include credentials, private keys, personal data, or other sensitive material.

## Supported versions

The latest tagged release on the default branch is the supported version for security-related fixes. Development branches may change without compatibility guarantees.
