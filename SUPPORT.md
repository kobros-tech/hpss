# Support

For questions about using HPSS, please open a GitHub issue with a minimal reproducible example when possible.

For suspected bugs, include:

- Python version
- operating system
- HPSS commit or release
- command used
- expected behavior
- observed behavior

For benchmark or research questions, also include the dataset, normalization settings, character budget, allocation, and relevant output.

Security-sensitive reports should not be posted publicly; use GitHub's private vulnerability-reporting mechanism if enabled for the repository.
